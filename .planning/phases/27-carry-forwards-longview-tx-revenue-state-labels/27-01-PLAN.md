<objective>
Fix two corrupted Longview TX revenue category names in the database, then run AI enrichment
for all 15 Longview FY2026 revenue categories.

Purpose: The revenue data ($87.6M, FY2026) was loaded in a prior session via processRevenuePDF.js
but two depth-1 category names contain trailing garbage from the PDF parser: 'Police' (102 chars)
and 'Library' (91 chars) both have embedded whitespace + "0  0%" suffixes. These must be fixed
before enrichment, because enrichCategories.js derives name_key from the raw name — a corrupted
name_key will never match a clean category name in future runs, and the description would never
surface in the UI.

Output:
- 2 corrected budget_categories rows in treasury.budget_categories
- 15 new category_enrichment rows for Longview TX municipality
</objective>
