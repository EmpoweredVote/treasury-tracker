# Plan 127-02 — Live UAT + defect fix + sign-off

**Mode:** standard
**Goal:** Prove the Essentials tether is context-sensitive end-to-end in the deployed app
(TETH-03) and pass Chris's live-app UAT across every entity tier (VER-01), fixing any defect
in-phase (D-127-03) so the milestone stays self-contained. The phase closes only when the
full 127-UAT matrix is green and Chris has signed off.

**Locked decisions (127-CONTEXT.md):** geoid-less covered → NO icon is correct, not a bug
(D-127-01); uncovered negative case required (D-127-02); verify-and-fix within this phase
(D-127-03); pass bar = visual correctness + live network behavior (D-127-04); concrete matrix
(D-127-05, as corrected in 127-01 — Fresno CA is the uncovered city, not Plano).
**Project gate note:** `npm run lint` is a broken gate in TT (13 pre-existing errors, 2
warnings) — any fix is gated on a lint DELTA of zero new problems vs the pre-fix baseline,
NOT on a green lint exit.

<threat_model>
**T-127-02 — Defect fixes touch the untrusted-catalog → external-href surface (T-126-01).**
Any fix in `featureIcons.ts`/`essentialsCoverage.ts` could regress the same-origin guard or
re-introduce string-concatenated hrefs.
- *Surface:* `buildEssentialsHref` (federal same-origin guard; URLSearchParams encoding); the
  fetch/shape-check in `essentialsCoverage.ts`.
- *Mitigations (this plan):* fixes must preserve URL/URLSearchParams-only construction and the
  federal `startsWith('/') && !startsWith('//')` + origin-equality guard; the existing vitest
  suite (incl. the hostile-target and protocol-relative cases) must stay green after every fix;
  every chip keeps `rel="noopener noreferrer" target="_blank"`; no `dangerouslySetInnerHTML` added.
- *Block on:* high. No new high-severity surface — this plan only repairs, and re-verifies, the
  Phase-126 guard.
</threat_model>
