**T-127-01 — Smoke script parses untrusted remote catalog JSON.** `scripts/essentials-live-smoke.mjs`
fetches and parses a remote JSON body TT does not control.
- *Surface:* the fetched `coverage.json` body; the header read.
- *Mitigations (this plan):* the script only READS fields and compares them to expected
  literals — no `eval`, no dynamic `require`, no URL/DOM construction, no shell interpolation

  use). No product code path is added or changed.
- *Block on:* high. No high-severity threat introduced (read-only public data, dev-only script).
</threat_model>
