# Plan 51-02 — Comparability content (sourced)

**Mode:** standard
**Goal:** Author the comparability copy — detailed per-area (D-01) but citizen-legible — entirely
from fetched official text, stored in a committed, cited data file. **Sourcing is the gate:** every
sentence traces to OMB Historical Tables / the PBD User's Guide / an enabling public law. No
model-memory claims (v2.0 ground rule). $0 — inline authoring from fetched text (federal-enrichment.json pattern).

<threat_model>
**T-51-02 — Unsourced or inaccurate comparability claims ship as authoritative.**
- *Threats:* drift facts written from memory; a "source" URL that doesn't actually contain the claim; dates/public-law numbers wrong.
- *Mitigations:* fetch the OMB Historical Tables Introduction + PBD User's Guide text for the TQ + function-classification statements and quote/paraphrase faithfully with the exact source_url; source each agency reorganization to its enabling public law via GovInfo (PLAW package, the Phase 47 PASS-class pattern) and verify the law # + year against the fetched record; a verifier script checks every source_url resolves.
- *Block on:* high (sourcing integrity — this is the milestone's core promise).
</threat_model>
