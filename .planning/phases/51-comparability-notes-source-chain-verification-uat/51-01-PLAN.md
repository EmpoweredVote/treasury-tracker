# Plan 51-01 — Source-chain durability + audit + spot-checks

**Mode:** standard
**Goal:** Make every backfilled federal figure resolve to a *durable* official source (not a
version-specific file that breaks next OMB edition, not raw API JSON), prove it with the audit
(zero residue), and spot-check representative years against the published OMB tables. (Criteria 2 + 3.)

<threat_model>
**T-51-01 — A "durability fix" breaks sourcing honesty or the audit.**
- *Threats:* (a) repointing a metric source_url to a page that doesn't actually host the figure (mis-sourcing); (b) a bulk UPDATE hitting unintended rows; (c) the audit passing only because a URL 200s today.
- *Mitigations:* repoint only to the canonical OMB pages that DO host the data (supplemental-materials = PBD home; historical-tables = Hist tables; fiscaldata dataset pages) — all verified human pages; scope each UPDATE with a precise `WHERE source_url LIKE` + row-count check before/after; the audit asserts resolution AND a SQL assertion forbids version-specific patterns going forward.
- *Block on:* high (sourcing integrity).
</threat_model>
