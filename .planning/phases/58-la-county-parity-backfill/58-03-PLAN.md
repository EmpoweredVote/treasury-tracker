# Plan 58-03 — Per-city basis note (basis-change disclosure)

**Mode:** standard
**Goal:** Implement decision **D-08**: when a city's displayed budget series mixes bases across the year axis — specifically the cities this phase layers SCO **all-governmental-funds** history beneath their **General-Fund / transaction** custom recent years (Long Beach, West Hollywood) — surface a short, sourced, expandable note so a citizen doesn't misread a basis seam as a real spending change. Reuse the existing `ComparabilityNote` + `SourceChip` disclosure pattern (federal Phase 51) and the all-funds gap-explanation precedent in `PlainLanguageSummary`. This is the honesty half of HIST-01.

**Design decision (no new UI-SPEC needed):** this reuses the already-shipped `ComparabilityNote.tsx` (expandable sourced panel) and `SourceChip.tsx` — no new visual design. The note content is **curated + sourced** (not auto-generated prose), keyed to the affected cities, and gated so it only appears where a basis seam actually exists.

**Data signal:** the affected cities are known and small (Long Beach, West Hollywood — the D-04 layered set). Use a curated `src/data/cityBasisNotes.ts` module (mirroring `src/data/comparability.ts`) keyed by city identifier, each entry carrying the sourced note text + SourceChip fields. Gate display on (a) the city having an entry AND (b) — if the loaded data exposes per-year `data_source`/basis — the city's series actually spanning >1 basis. If per-year basis is not available to the frontend, the curated-entry gate alone is acceptable and accurate (the entries are authored only for cities that genuinely mix bases this phase).

<threat_model>
**T-58-03 — A disclosure note misleads (unsourced, wrong city, or shown where no seam exists).**
- *Surface:* a React render path that shows note prose on city pages.
- *Threats:* (1) unsourced prose (violates the always-sourced ground rule); (2) the note shown on a single-basis city (false alarm) or absent on a mixed-basis one (silent omission); (3) a render regression on pages with no note.
- *Mitigations:* (1) every note line renders a `SourceChip` (the data module requires source_name/url/date — no entry without a source); (2) display gated on a curated entry authored only for genuinely-mixed cities (Long Beach, West Hollywood), verified against the actual loaded series in task 03; (3) the note is additive — absent entry ⇒ nothing renders ⇒ no change for the ~85 pure-SCO cities, Los Angeles, counties, or federal.
- *Block on:* high (always-sourced). No note entry may ship without a SourceChip.
</threat_model>
