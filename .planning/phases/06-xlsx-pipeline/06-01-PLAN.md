<task type="auto">
  <name>Task 2: Implement download + parse + hash + buildBatch helpers</name>
  <files>scripts/bulkLoadXLSX.js</files>
  <action>
Implement the four pure helpers in `bulkLoadXLSX.js`:

**`downloadXLSX(url)`** — async fetch with redirect:'follow':
- `const resp = await fetch(url, { redirect: 'follow' });`
- If `!resp.ok`: `console.error('Download failed: ' + url + ' — HTTP ' + resp.status); process.exit(1);` (fail-fast per CONTEXT decision)
- Optional: log a warning if `content-type` doesn't include 'spreadsheet'/'excel'/'octet-stream' but DO NOT fail (some servers return generic content-type for working XLSX)
- Return `Buffer.from(await resp.arrayBuffer())`

**`parseXLSX(buffer)`** — async ExcelJS load + iterate:
- `const workbook = new ExcelJS.Workbook(); await workbook.xlsx.load(buffer);`
- `const worksheet = workbook.worksheets[0];` (first sheet only — government XLSX exports use single-sheet convention)
- Track: `headers = []`, `rows = []`, `blankSkipped = 0`, `headerDupeSkipped = 0`
- Use `worksheet.eachRow((row, rowNumber) => { ... })`:
  - `const values = row.values.slice(1);` — CRITICAL: ExcelJS row.values[0] is always null (research §Pitfall 1)
  - If `rowNumber === 1`: normalize headers — `headers = values.map(v => String(v ?? '').trim().toLowerCase().replace(/\s+/g, '_'));` and return
  - Skip blank: if `values.every(v => v == null || v === '')` increment `blankSkipped` and return
  - Build `obj` by zipping `headers` with `values` (default null for missing): `headers.forEach((h, i) => { obj[h] = values[i] ?? null; })`
  - Skip header-duplicate: if `headers.some(h => String(obj[h] ?? '').toLowerCase() === h)` increment `headerDupeSkipped` and return (research §Pitfall 7)
  - For ExcelJS Date cells: if `values[i] instanceof Date`, convert to ISO date string `values[i].toISOString().slice(0, 10)` so the date_column maps cleanly to a string the RPC accepts
  - For ExcelJS rich-text cells (object with .richText): flatten to `obj[h] = values[i].richText.map(t => t.text).join('')` (some payee fields use rich text)
  - Push `obj` to `rows`
- Return `{ headers, rows, blankSkipped, headerDupeSkipped }`

**`hashRow(obj)`** — deterministic SHA-256:
- Sort keys: `const sorted = Object.keys(obj).sort().reduce((acc, k) => { acc[k] = obj[k] instanceof Date ? obj[k].toISOString() : obj[k]; return acc; }, {});`
- Return `createHash('sha256').update(JSON.stringify(sorted)).digest('hex')`
- Critical: keys must be sorted BEFORE JSON.stringify or hash is non-deterministic across runs (research §Pitfall 4)

**`parseAmount(v)`** — numeric coercion (copy from bulkLoadBudget.js parseAmount):
- Returns 0 for null/empty
- Returns v if already a number
- Strips `$`, `,`, converts `(123)` to `-123`, parseFloat

**`buildBatch(rows, cm)`** — adapt from bulkLoadTransactions.js:
- Track `vendors = new Set()`
- Map rows to compact transaction objects with the same short keys as bulkLoadTransactions.js: `{ a, d, dt, pm, inv, f, ec, dept, prog, vn, lk, rid }`
- `a = parseAmount(r[cm.amount_column])`
- `vn = r[cm.vendor_column] || 'Unknown'` (also add to vendors set)
- `dt`: if `cm.date_column` and `r[cm.date_column]` is a Date object, ISO-string it; otherwise use raw value or null
- `lk` (lookup key): `[r[cm.department_column], r[cm.fund_column], r[cm.expense_category_column]].filter(Boolean).join('|') || null`
- `rid = hashRow(r)` — SHA-256 of full row, NOT cm.source_row_id_column (the entire row content is the dedup key for XLSX)
- Return `{ vendors: [...vendors].map(n => ({ n })), transactions: txns }`

8. Otherwise build batches and call RPC in chunks of 500:
   ```js
   const RPC_BATCH = 500;
   let totalInserted = 0, totalSkipped = 0;
   for (let i = 0; i < rows.length; i += RPC_BATCH) {
     const chunk = rows.slice(i, i + RPC_BATCH);
     const { vendors, transactions } = buildBatch(chunk, cm);
     const { data, error } = await supabase.rpc('treasury_sync_transactions', {
       p_data_source_id: ds.id,
       p_fiscal_year: ds.fiscal_year,
       p_vendors: vendors,
       p_transactions: transactions,
       p_row_count: chunk.length,
       p_triggered_by: 'bulk_xlsx_load',
     });
     if (error) { console.error('  RPC error at batch ' + i + ': ' + error.message); /* count toward errors */ continue; }
     totalInserted += data?.rows_inserted || 0;
     totalSkipped += data?.rows_skipped || 0;
     process.stdout.write('\\r  loaded ' + (i + chunk.length) + '/' + rows.length);
   }
   console.log('');
   ```
