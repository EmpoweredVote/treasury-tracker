# Plan 132-02 — Load the 4 Pima cities' GF operating + revenue

**Mode:** standard
**Goal:** Turn the Phase-131 extractor + RECON into live, sourced, navigable data for all four cities. Build `scripts/processPimaCities.js`, which runs `extractAcfrGF.py` across each city's locked window (both modes), maps the extractor tree to the RPC shape, and loads through the **source-safe `treasury_sync_budget_tree` RPC** — durable `source_url`+`source_date` on every row, ephemeral `data_sources`, idempotent re-run, and an Oro-Valley label-normalization pass.

Depends on 132-01 (the four municipalities must exist). No schema change, no enrichment (132-03).

<threat_model>
**T-132-02 — External binary over files + privileged bulk writes to shared production budget tables.**
- *Surface:* spawns `extractAcfrGF.py` (→ `pdftotext`) over `docs/<City>/` PDFs, then bulk-writes `treasury.budgets` via a service-role RPC.
- *Threats:* (a) shell injection via interpolated path; (b) silent mis-parse loading wrong numbers; (c) overwriting a foreign source's rows / stale rows on re-run; (d) parse blow-up; (e) `data_sources` residue; (f) mixing up one city's data into another's municipality_id.
- *Mitigations:* `spawnSync('py',['-3','scripts/extractAcfrGF.py',pdf,'--mode',mode])` **args array** (no `shell:true`); PDF paths from a controlled per-city `docs/<City>/` readdir; **trust the extractor's `tie_delta==0` fail-loud gate** AND independently re-derive the loaded total against the `131-RECON.md` printed total; **source-safe RPC** with per-`(data_source_id,fiscal_year)` pre-load delete; distinct `dataset_id` per (city,mode); resolve each city's municipality_id by (name,state,entity_type) and refuse to write if not found; **ephemeral `data_sources`** (delete at run end); per-FY sanity ceiling.
- *Block on:* high (bad/overwriting writes corrupt shared production data).
</threat_model>
