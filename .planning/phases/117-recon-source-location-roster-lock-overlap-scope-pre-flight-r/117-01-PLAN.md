<objective>
Recon the Batch-1 states of the v2.15 final tail — **AK, AR, DE, HI, ID** — for the State-ACFR upgrade. For each state, FIRST run the D-03 triage ("does a GAAP Governmental Funds ACFR with a splittable GENERAL FUND column even exist?"), then — for states that pass — locate the ACFR Governmental Funds *Statement of Revenues, Expenditures and Changes in Fund Balances* → **GENERAL FUND column** (GAAP), find its durable per-year URL pattern, establish the cleanly `pdftotext -table`-extractable clean window, bookend-tie-confirm that window (oldest + latest FY), pin the four risk facts (D-08), check the recency floor (D-07), compare ACFR GF scope vs NASBO (D-09), map the closest loader template, and gap-log every year that doesn't cleanly extract or lacks a durable URL. States that fail triage are recorded as stay-NASBO-exception candidates (D-01) — never silently dropped (D-11).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public state ACFR site → local disk | untrusted PDF/HTML fetched over the network into a local working dir |

This is a documentation-only, read-only recon plan: it fetches public ACFR PDFs, runs `pdftotext`, and writes local markdown. No DB, no secrets, no user input, no network writes. The honest threat surface is minimal.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-117-01 | Spoofing/Tampering | a fetched "ACFR" PDF that is actually a soft-404 HTML page (HTTP 200 + HTML body) mistaken for a real document | mitigate | Filter every download by Content-Type `application/pdf` or size (>~1MB), never by HTTP status alone (CA-SCO soft-404 caution, 98-RECON). Confirm the exact statement title + "General Fund" column header + units before trusting any extracted figure. |
| T-117-02 | Tampering | extracting the wrong statement (government-wide Statement of Activities, or a budgetary/forecast schedule) instead of the Governmental Funds GENERAL FUND column — higher risk in small states that may only publish a budgetary document | mitigate | Confirm the statement title is "Statement of Revenues, Expenditures and Changes in Fund Balances — Governmental Funds" and the column header is the General Fund column; tie the extracted GF Total revenues to the printed page total before recording (D-05/D-08.3). If only a budgetary basis exists, record it as a D-01/D-09 accept-relabel candidate, not as GAAP. |
| T-117-03 | Tampering | recording a non-durable (Wayback/one-off) URL that will rot, breaking the always-sourced standard | mitigate | Reject non-durable-only years to the gap log (D-06); only a stable re-fetchable per-year URL pattern is recorded as loadable. A tie-confirmed total never overrides durability. |

No package installs in this plan (poppler `pdftotext` is a pre-existing system tool) → no supply-chain checkpoint needed.
</threat_model>
