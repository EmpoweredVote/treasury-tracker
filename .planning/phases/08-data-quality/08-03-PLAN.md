**Step 1 — BEFORE audit:**

Run the SQL audit (same query family as Plan 02, scoped to Frisco + Plano):

```sql
SELECT
  m.name AS city,
  b.fiscal_year,
  COUNT(*) FILTER (WHERE bdi.name = 'Unknown') AS unknown_rows,
  COUNT(*) AS total_rows,
  ROUND(100.0 * COUNT(*) FILTER (WHERE bdi.name = 'Unknown') / NULLIF(COUNT(*), 0), 1) AS pct_unknown
FROM treasury.budget_items bdi
JOIN treasury.budgets b ON bdi.budget_id = b.id
JOIN treasury.municipalities m ON b.municipality_id = m.id
WHERE m.name IN ('Frisco', 'Plano')
  AND b.dataset_type = 'operating'
GROUP BY m.name, b.fiscal_year
ORDER BY m.name, b.fiscal_year;
```
