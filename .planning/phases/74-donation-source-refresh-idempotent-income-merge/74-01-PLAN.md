<objective>
Build `scripts/loadEVDonations.js` — the single, idempotent writer of Empowered Vote's donation **income** for the current fiscal year, sourced from per-platform CSV exports (GiveButter, Patreon, Benevity) instead of the hand-entered Google Sheet. Aggregate GROSS donations by source, capture per-source platform fees, and reconcile GiveButter so the live webhook never double-counts the export (D-04). Retire the three platforms' income from `loadEVFinances.js` (D-08) so there is exactly one income writer. Prove it all with offline unit tests on fixtures.

Purpose: this is the income engine for the whole milestone. Getting the dedup + idempotency contract right here is what makes EVDATA-01/02/03 true and de-risks the live load (74-02) and the Phase 75 bank reconciliation.
Output: new loader + offline tests + a pinned per-platform mapping doc + a modified `loadEVFinances.js` that no longer writes platform income.
</objective>
