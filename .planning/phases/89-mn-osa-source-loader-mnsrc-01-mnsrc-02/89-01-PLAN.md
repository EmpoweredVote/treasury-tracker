MN OSA source (no auth, free — recon: auto-memory reference_minnesota_osa_finances_report):
- Cities landing page: https://www.osa.state.mn.us/reports-data-analysis/local-government/cities/
- Counties landing page: https://www.osa.state.mn.us/reports-data-analysis/local-government/counties/
- All datasets: https://www.osa.state.mn.us/reports-data-analysis/reports/local-government-finances-report/
- City raw-data file URL pattern (CONFIRMED): https://www.osa.state.mn.us/media/<slug>/cired_<YY>_data.xlsx — `cired` = City Income, Revenues, Expenditures & Debt. 2023 = /media/x30lkoud/cired_23_data.xlsx. XLSX from 2015+; ZIP 2004-2014; CSV 2002-2003 (the pre-2015 floor — document, do NOT load).

cired_23_data.xlsx structure (city file, recon-confirmed): 5 sheets — `Governmental Funds` (859 rows x 148 cols = THE icicle source, one row per city), `Enterprise Funds`, `Debt`, `Fund Balance`, `Employee Data` (last four deferred to v2).

`Governmental Funds` columns (recon-confirmed):
- Identity: GovEntityID, Entity Name, ParentEntityName (= the COUNTY — built-in city->county link), Entity Type, ClassCode, GAAPInd (GAAP vs Cash basis flag), Population (per-capita built in), FinancialYear.
- Revenue-by-source (cols ~11-73): PropertyTaxes, Tax Increments, FranchiseFees, SalesTax, HotelMotelTax, Special Assessments, Licenses and Permits, federal grants by type -> `Total Federal Grants`, state aids by type (incl. State Local Government Aid/LGA) -> `Total State Grants`, county/local grants -> `Total Intergovernmental Revenues`, charges-for-services by function -> `Total Charges for Services`, Fines and Forfeits, Interest Earnings -> `Total Revenues` (+ `Total Revenues & Other Sources` incl. bonds/transfers — EXCLUDE per D-05).
- Expenditure-by-function (cols ~81-147): General Government, Public Safety (Police/Fire/Corrections/Ambulance, current + capital), Streets & Highways (admin/maint/snow/eng/lighting/construction), Sanitation, Human Services, Health, Library, Park & Recreation, Housing & Urban Redevelopment, Economic Development, Conservation, Airport, Transit, Cemetery, Education — each split current-expend vs capital-outlay -> `Total Current Expenditures` + `Total Capital Outlay` + debt service -> `Total Expenditures` (+ `Total Expenditures & Other Uses` — EXCLUDE per D-05).
