    1. Replace `parse_fy_from_header` with a dash-format parser: `re.findall(r'(\d{4})-(\d{2})(?!\d)', header_line)`, take the LAST match (Adopted column), compute ending year as `(int(yyyy)//100)*100 + int(yy)`. Troutdale uses `2025-26` (dash), not `2025/26` (slash) — the Gresham slash regex returns zero matches (Pitfall 3).

    2. In `extract_budget` (operating mode), replace the All-Funds page detection with General Fund page detection: require `'GENERAL FUND' in text and 'FUND SUMMARY' in text`, then `if 'ACCOUNT 01.00' not in text: continue` (skip other fund pages). Troutdale's department-level data is on the General Fund page, NOT the All Funds page (Pitfall 1).

    3. Set the operating `SKIP_ROWS` to exactly: `'TOTAL REQUIREMENTS'`, `'APPROPRIATIONS:'`, `'TRANSFERS'`, `'CONTINGENCY'`, `'UNAPPROPRIATED'`, `'OTHER'`, `'PUBLIC SAFETY'`, `'COMMUNITY DEVELOPMENT'`, `'PARKS & FACILITIES'`. The three two-word rows are subtotals that double-count their child departments (Pitfall 2). Also skip any name ending in `:`.

    4. Add a `finance_count` guard inside the operating loop: the General Fund page has two `FINANCE` rows — the first is the Finance department ($939,995 FY2026), the second is a Finance+Information Services subtotal ($1,389,227). Increment a counter when `dept == 'FINANCE'` and `continue` when the count exceeds 1 (keep only the first).

    5. Use UPPERCASE section markers for Troutdale: operating section flips on when the whitespace-stripped line equals `'REQUIREMENTS'`. Revenue mode flips `in_resources` on when the line equals `'RESOURCES'` and off when it equals `'REQUIREMENTS'`.

    6. In the token-split clean step, strip dollar signs as well as commas before the numeric check: `clean_t = re.sub(r'[\$,]', '', t)`, and treat a standalone `$` as the start of the numeric region. Troutdale rows contain a standalone `$` token between name and first number (Pitfall 4).

    7. Adapt `extract_revenue` to Troutdale: require `'ALL FUNDS COMBINED' in text and 'FUND SUMMARY' in text`, and add the guard `if 'ACCOUNT 01.00' in text: continue` so the General Fund page (which also has a Resources section) is skipped (Pitfall 6). Set `REVENUE_SKIP = {'BEGINNING FUND BALANCE', 'TOTAL RESOURCES'}` and also skip a parsed name of `'BEGINNING FUND BALANCE $'` (the standalone `$` may attach to the name). Including Beginning Fund Balance inflates the revenue total to ~$81M instead of ~$33.7M (Pitfall 5).

    Keep the Gresham `NORMALIZE` dict only if it is harmless for Troutdale; Troutdale verified years had no OCR name artifacts, so an empty or absent NORMALIZE dict is acceptable. Do NOT use `extract_tables()` — it returns empty on both Troutdale pages; text-line parsing is required.
