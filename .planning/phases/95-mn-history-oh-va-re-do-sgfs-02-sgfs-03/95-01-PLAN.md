<interfaces>
The loader template is processMN.js itself (extended in place). Key contracts:

Per-FY SOURCES entry shape: { url: '<resolving mn.gov ACFR PDF URL>', date: 'YYYY-06-30' }
Per-FY EXPENDITURES entry shape: { total: <reported GF Total Expenditures, in $>, confidence: 'actual', categories: [ { name: '<verbatim ACFR function name>', total: <$>, lineItems: [] }, ... ] }
data_source label (already in file): the function dataSource(fy) returns "State of Minnesota ACFR — General Fund (FY<fy> actual)".
validate(fy): sums categories, aborts if catSum differs from total by > $10M.
buildTree(fy): returns jsonTree root "Minnesota General Fund Budget" with depth-1 children, plus total + rowCount.
RPC: treasury_sync_budget_tree (p_data_source_id, p_fiscal_year, p_dataset_type='operating', p_total, p_tree, p_row_count, p_triggered_by).
Post-RPC stamp: UPDATE treasury.budgets SET source_url, source_date, data_source WHERE id=<row id>. Do NOT set data_source_id.
</interfaces>
