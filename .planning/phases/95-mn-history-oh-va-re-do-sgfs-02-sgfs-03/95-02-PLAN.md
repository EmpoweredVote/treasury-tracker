<interfaces>
processMNRevenue.js is the loader template (extended in place). Key contracts:

Per-FY SOURCES entry: { url: resolving mn.gov ACFR PDF URL, date: YYYY-06-30 } (same URL map as plan 01).
Per-FY REVENUE entry: { total: audited Net Revenues in $, confidence: actual, categories: [ { name: verbatim ACFR source name, total: $ (may be negative for FY2022 investment line), lineItems: [] }, ... ] }
dataSource(fy) returns "State of Minnesota ACFR — General Fund Revenue (FY<fy> actual)".
validate(fy): sums categories, aborts if catSum differs from total by > $10M (sums signed values, so the FY2022 negative is included).
buildTree(fy): CURRENTLY filters categories with c.total > 0 — this filter must become P2-aware (see Pitfall 6).
RPC: treasury_sync_budget_tree (..., p_dataset_type=revenue, ...). Post-RPC stamp identical to plan 01. Do NOT set data_source_id.
</interfaces>
