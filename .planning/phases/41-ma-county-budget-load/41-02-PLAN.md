| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-41-04 | Tampering | upsertDataSource api_type | mitigate | api_type hardcoded as 'pdf_download' in upsertDataSource function — not from user input or PDF content |
| T-41-05 | Elevation of Privilege | SUPABASE_SERVICE_KEY in .env | accept | Service key already in .env for all other loaders; no new exposure; .env is gitignored |
| T-41-06 | Tampering | county_id bleed to city queries | accept | entity_type='county' filter in ensureMunicipality prevents city municipality_id mismatch; DB query verification confirms no city bleed |

</threat_model>
