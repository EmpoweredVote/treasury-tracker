<key_facts>
- enrichCategories.js flags: `--city Sacramento --state CA --year YYYY`. Also `--dry-run` (no DB write, no cost confirmation needed), `--force` (re-enrich), `--depth` (default '0' = top-level only). It enriches only categories for the `--year` budget that are not already enriched (idempotent via name_key + municipality_id upsert).
- The script REQUIRES ANTHROPIC_API_KEY, SUPABASE_URL, and SUPABASE_SERVICE_ROLE_KEY (or SUPABASE_ANON_KEY) in env. It exits 1 if ANTHROPIC_API_KEY is missing.
- Cost is per-category; estimated ~$0.06 total across all 7 v1.6 CA cities (STATE.md). Sacramento alone is a small fraction. The project API cost threshold is $5 — Sacramento enrichment is far under it, so no approval checkpoint is needed before running.
- The year to enrich must match an actually-loaded FY from Plan 26-01 (read 26-01-SUMMARY.md for the FY list). enrichCategories.js processes one `--year` per invocation and silently skips a year with no budget categories.
- App URL: treasurytracker.empowered.vote (per MEMORY.md). Sacramento appears under "California" automatically once it has budget data — no frontend code change in this phase.
</key_facts>
