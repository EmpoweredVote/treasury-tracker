# Plan 53-01 — Load Orange County operating + revenue (FY2003–2024)

**Mode:** standard
**Goal:** Run Step 1 (bulk load) of `docs/socal-county-onboarding.md` against Orange County for FY2003–2024, loading operating + revenue for all 34 cities and auto-creating the 32 net-new city records with populations, then verify (Step 4). No code is written — this executes the already-shipped, hardened `scripts/bulkLoadStateController.js`. County seed/link + enrichment are Phase 54.

<threat_model>
**T-53-01 — A county-wide run overwrites Anaheim's / Santa Ana's richer custom-sourced budgets.**
- *Surface:* `bulkLoadStateController.js --county "Orange"` enumerates every SCO city in the county, which includes Anaheim and Santa Ana — both already hold custom-sourced data the milestone decided to keep (CONTEXT D-04).
- *Threats:* if the collision pre-pass failed to fire, ByTheNumbers rows would upsert over the custom data, silently destroying detail. Secondary threat: a silently partial load (missing years/cities) that still "looks" successful.
- *Mitigations:* the loader's collision pre-pass (Phase 52, locked convention #3) classifies and SKIP-logs existing-source cities **before any write**. This plan additionally gates the real write behind a mandatory `--dry-run --list-cities` pass that MUST show 34 cities and Anaheim/Santa Ana as SKIP before proceeding; and verifies post-load that Anaheim/Santa Ana budget rows still carry their original `data_source` (not ByTheNumbers).
- *Block on:* high. Do not run the real load (task 53-01-02) until the dry-run output (task 53-01-01) is read and confirms 34 cities found with Anaheim & Santa Ana classified as SKIP.
</threat_model>
