# Plan 53-01 — Load Orange County operating + revenue (FY2003–2024)

**Mode:** standard
**Goal:** Run Step 1 (bulk load) of `docs/socal-county-onboarding.md` against Orange County for FY2003–2024, loading operating + revenue for all 34 cities and auto-creating the 32 net-new city records with populations, then verify (Step 4). No code is written — this executes the already-shipped, hardened `scripts/bulkLoadStateController.js`. County seed/link + enrichment are Phase 54.

**Load shape (CONTEXT D-06):** a single 22-year run is ~450k fetch+write rows and would exceed the 600s command timeout. So: dry-run → **canary one year (FY2024)** → verify the canary end-to-end → **backfill FY2003–2023 in 2-year submits** → final verify. Each submit is idempotent for ByTheNumbers data (`treasury_sync_city_budget` upserts on (municipality, fiscal_year, dataset_type)), so any chunk is safe to re-run.

<threat_model>
**T-53-01 — A county-wide run overwrites Anaheim's / Santa Ana's richer custom-sourced budgets.**
- *Surface:* `bulkLoadStateController.js --county "Orange"` enumerates every SCO city in the county, which includes Anaheim and Santa Ana — both already hold custom-sourced data the milestone decided to keep (CONTEXT D-04).
- *Threats:* if the collision pre-pass failed to fire, ByTheNumbers rows would upsert over the custom data, silently destroying detail. Secondary threat: a silently partial load (a chunk timing out / missing years) that still "looks" successful.
- *Mitigations:* the loader's collision pre-pass (Phase 52, locked convention #3) classifies and SKIP-logs existing-source cities **before any write**. This plan gates the full backfill behind a verified single-year **canary** (task 03), keeps each submit small enough to finish inside the command timeout (D-06), captures every chunk's imported/skipped summary, and at the end verifies Anaheim/Santa Ana budget rows still carry their original (non-ByTheNumbers) `data_source`.
- *Block on:* high. Do not start the backfill (task 04) until the canary (task 03) verifies clean: source attribution, population, and a matched spot-check total, with Anaheim/Santa Ana untouched.
</threat_model>
