# Plan 52-02 — Reusable, sourced, collision-safe county loader

**Mode:** standard
**Goal:** Turn `bulkLoadStateController.js` into the one-command, fully-sourced county loader the milestone needs — passing durable source attribution (via the Plan 52-01 RPC), persisting per-year population from the feed, and refusing to clobber cities already loaded from another source. No Orange County data is loaded here (that is Phase 53); this plan hardens the mechanism and is validated by dry-run in Plan 52-04.

<threat_model>
**T-52-02 — Re-running the loader overwrites richer custom-sourced city data.**
- *Surface:* `treasury_sync_city_budget` upserts on (municipality, fiscal_year, dataset_type); Anaheim, Santa Ana, and the City of Los Angeles already hold custom-sourced budgets the milestone decided to keep.
- *Threats:* a county run that includes those entity_names would upsert ByTheNumbers data over the custom data, silently destroying detail.
- *Mitigations:* before importing a city, query whether a budget already exists for that (municipality, fy, dataset) whose data_source is NOT the ByTheNumbers source; if so, skip the import and log `SKIP <city> — existing <source> data preserved`; only import cities with no conflicting prior source. This is enforced in the loader (the RPC itself stays a dumb writer).
- *Block on:* high. The skip check must run before every import call.
</threat_model>
