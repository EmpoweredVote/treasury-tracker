# Plan 52-03 — Reusable county seed + link helper

**Mode:** standard
**Goal:** Replace the per-county `seedLACountyLinks.js` pattern with a generic, parameterized `scripts/seedCountyLinks.js` so seeding a county entity and linking its cities is one command for any SoCal county (CONTEXT D-05). This is the second half of PIPE-01's "one command" promise. It only writes `county_id` / creates a county entity — no budget data — so it never conflicts with the never-overwrite policy.

<threat_model>
**T-52-03 — Mislinking cities to the wrong county or duplicating county entities.**
- *Surface:* writes `treasury.municipalities.county_id` and may create a county `municipalities` row.
- *Threats:* (a) creating a duplicate county entity on re-run; (b) linking cities outside the county; (c) overwriting an existing correct county_id.
- *Mitigations:* upsert the county entity by (name, state, entity_type='county') — reuse if present; derive membership strictly from the SCO `county` field for the given county+state; only set county_id where it is currently NULL or already points at this county (never repoint a city already linked elsewhere without an explicit `--force`).
- *Block on:* medium.
</threat_model>

## Tasks

<task id="52-03-01" type="execute">
<action>
Create `scripts/seedCountyLinks.js` modeled on `scripts/seedLACountyLinks.js` but parameterized with `--county "<Name>"` and `--state CA` (default CA), plus `--dry-run`. Behavior: (1) ensure a county entity exists via `treasury_ensure_municipality(p_name="<County> County", p_state, p_entity_type='county', p_population=0)`, reusing if present; (2) fetch the distinct `entity_name` set for that county from ByTheNumbers (dataset ju3w-4gxp, `$where=county='<Name>'`, a recent fiscal_year, `$group=entity_name`) — same source as the loader so membership matches; (3) for each city municipality in (treasury.municipalities) matching those names + state, set `county_id` to the county entity's id WHERE county_id IS NULL or already equals this county; (4) print a summary of linked / already-linked / skipped (linked-elsewhere) cities.
</action>
<read_first>
- scripts/seedLACountyLinks.js (the per-county pattern to generalize — entity creation + county_id update)
- scripts/bulkLoadStateController.js (Socrata fetch + county filter convention, lines 34-51, 155-169)

</read_first>
<acceptance_criteria>
- `node scripts/seedCountyLinks.js --county "<X>" --dry-run` lists the county entity action + the cities it would link, with no writes

- A second run is idempotent: re-running reports cities as already-linked and creates no duplicate county entity
- Cities already linked to a different county are reported as skipped, not repointed (absent `--force`)
</acceptance_criteria>
</task>
