# Plan 98-02 — ACFR source location + full-window pre-extract

**Mode:** standard
**Goal:** For CA, TX, NY, and FL, locate the published ACFR Governmental Funds *Statement of Revenues, Expenditures and Changes in Fund Balances* (General Fund column, GAAP, in thousands), record a durable source URL, and — per the full-window pre-extract decision (D-06) — `pdftotext`-extract and sample-verify every cleanly-extractable FY now, applying the clean-extract bar (D-07/D-08) and recording dropped FYs in a gap log. Extraction only; no DB writes. Satisfies RECON-02 and makes Phases 99–100 near-mechanical.

<threat_model>
**T-98-02 — A mis-located statement or an under-validated extraction lets a wrong/garbled GF column flow into the Phase 99–100 loads.**
- *Surface:* downloading public ACFR PDFs to a local working dir; running pdftotext; recording URLs + FY depth + gap log.
- *Threats:* (a) extracting the government-wide Statement of Activities or a budgetary schedule instead of the Governmental Funds statement's GENERAL FUND column; (b) a CDN/TLS block silently yielding an HTML error page saved as ".pdf"; (c) a misaligned column producing plausible-but-wrong numbers that still "tie"; (d) claiming a FY is clean without verifying the total ties.
- *Mitigations:* verify the exact statement title + that the column header reads "General Fund" + units "(in thousands)" before extracting; confirm each download is a real PDF (file type / page count), not an error page; for every kept FY confirm the extracted GF total ties to the printed total on the page; gap log records every dropped FY with reason; durable URLs recorded so 99–100 re-fetch the same artifact.
- *Block on:* high.
</threat_model>
