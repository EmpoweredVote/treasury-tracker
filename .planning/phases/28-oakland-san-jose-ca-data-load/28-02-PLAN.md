| remote S3 PDF → local disk | Untrusted PDF content parsed by pdfplumber (no code execution; data only) |

| T-28-05 | Tampering | Command injection via PDF path in execSync | mitigate | PDF path from readdirSync(docs/Oakland/) only, never user input; path double-quoted in the execSync command string (processPortland.js T-17-03 pattern) |
