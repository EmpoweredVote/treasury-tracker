Do NOT pass --force. The script is idempotent; re-running on already-enriched categories is a no-op and avoids re-billing API calls. Step B — DB verification via mcp__supabase-local__execute_sql (per project memory: prefer Supabase MCP over manual Dashboard checks).

Run these queries and confirm results:

1. Combined count + NULL check for all three cities in one query:
   ```sql
   SELECT
     m.name AS city,
     COUNT(ce.*) AS total,
     COUNT(*) FILTER (WHERE ce.municipality_id IS NULL) AS null_count,
     COUNT(*) FILTER (WHERE ce.description IS NULL OR ce.description = '') AS blank_desc
   FROM treasury.category_enrichment ce
   JOIN treasury.municipalities m ON m.id = ce.municipality_id
   WHERE ce.municipality_id IN (
     'bc67db4a-cfc0-4d76-b053-1e4ca69f0b85',  -- Sachse
     '1bddfc90-01cb-4f6b-89c3-ac011c0bd532',  -- Murphy
     '43f10ae9-6789-47d0-9ddc-8078192062d2'   -- Princeton
   )
   GROUP BY m.name
   ORDER BY m.name;
   ```
