## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| processCA.js → extractCA.py | Shell execSync call with hardcoded script path — no user input reaches the path |
| extractCA.py → docs/California/Historical_Expenditures.xlsx | Reading a locally downloaded file from the official LAO source |
| processCA.js → Supabase RPC | Service key from .env; parameterized RPC call, no SQL injection surface |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-33-06 | Tampering | Amount units error (thousands passed as dollars, giving $228M not $228B) | mitigate | Sanity check lower bound $150B catches this immediately — $228M is 1000x below $150B; process.exit(3) |
