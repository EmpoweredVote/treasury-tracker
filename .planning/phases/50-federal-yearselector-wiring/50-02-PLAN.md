# Plan 50-02 — Frontend period model + selector + data-layer

**Mode:** standard · **Depends on:** 50-01 (API exposes `period_label`)
**Goal:** Teach the frontend that a federal "period" can be an annual year or the Transition
Quarter, list both in the selector, and fetch the correct budget by `period_label`.

<threat_model>
**T-50-02 — Period-token refactor breaks year handling for all entities.**
- *Surface:* `selectedYear` and `parseInt(selectedYear)` are used across App.tsx for every entity (city/state/federal).
- *Threats:* a missed `parseInt` call site receiving a non-numeric TQ token → NaN year → broken fetch/regression for cities too.
- *Mitigations:* one `parsePeriod` helper, route every call site through it; annual tokens stay plain `'YYYY'` so city/state behavior is unchanged; tsc + explicit city/state regression in 50-04.
- *Block on:* high (cross-entity regression).
</threat_model>

## Tasks

<task id="50-02-01" type="execute">
<action>
Create `src/utils/period.ts` exporting `parsePeriod(token: string) => { fiscalYear: number; periodLabel: string | null; label: string; shortLabel: string }` and a `TQ_TOKEN` constant (e.g. `'1976-TQ'`) + `tqLabel = 'Transition Quarter (Jul–Sep 1976)'`. Annual token `'YYYY'` → `{ fiscalYear: Number, periodLabel: null, label: 'FY YYYY', shortLabel: 'FY YYYY' }`; TQ token → `{ fiscalYear: 1976, periodLabel: tqLabel, label: tqLabel, shortLabel: 'Transition Q 1976' }`. Add `period_label?: string | null` to the `available_datasets` element type and to the budget type in `src/types/budget.ts`.
</action>
