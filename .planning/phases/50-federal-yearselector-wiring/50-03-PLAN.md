# Plan 50-03 — Per-year federal landing block

**Mode:** standard · **Depends on:** 50-02 (period model / selectedYear semantics)
**Goal:** Make the landing Mandatory/Discretionary/Net-Interest bands and the receipts-vs-outlays
deficit strip reflect the selected year (NAV-02). The context payload already carries every year's
`annual_summary` row — this is frontend-only.

<threat_model>
**T-50-03 — Wrong year's bands shown, or a crash when no summary row exists.**
- *Surface:* landing bands present official Mandatory/Discretionary/Net-Interest splits.
- *Threats:* (a) off-by-one selecting the summary row → a year's bands mislabeled; (b) the TQ (no annual_summary row) → `undefined` summary → crash or misleading FY1976 bands shown under a TQ heading.
- *Mitigations:* select by exact `fiscal_year` match; for the TQ (`periodLabel != null`) render no bands/strip (guarded), not a fallback year; keep the FY{year} heading bound to the matched row.
- *Block on:* high (data-integrity / correctness).
</threat_model>
