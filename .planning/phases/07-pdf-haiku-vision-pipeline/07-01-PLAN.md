**`downloadOrReadPDF(input)` — async, returns Buffer:**
- If `typeof input !== 'string' || !input.trim()`: `console.error('Config error: --pdf or ds.base_url missing'); process.exit(2);`
- If `input.startsWith('http')`:
  - `console.log('  Downloading PDF: ' + input);`

  - If `!resp.ok`: `console.error('Download failed: ' + input + ' — HTTP ' + resp.status); process.exit(2);` (exit 2 = fatal)
  - Optional: warn if `content-type` header doesn't include 'pdf' or 'octet-stream', but DO NOT fail (some CDNs return generic content-type for valid PDFs — research notes Prosper's URL goes through ArchiveCenter)

  - Strip `file://` prefix if present (mirror the bulkLoadXLSX.js pattern: `decodeURIComponent(input.replace(/^file:\/\/\/?/, '').replace(/\//g, path.sep || '\\'))` — but only when starting with `file://`; raw paths pass through as-is)

  - `return await fs.readFile(filePath);`

   const images = await pdftoimg(pdfBuffer, {
     scale: 2.0,                         // ~150-200 DPI; tune up if Haiku struggles with small text
