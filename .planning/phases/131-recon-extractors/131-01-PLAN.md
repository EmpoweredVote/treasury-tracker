# Plan 131-01 — Pima municipalities ACFR recon + window lock + South Tucson verdict

**Mode:** standard
**Goal:** Prove each municipality's ACFR source is loadable end-to-end before any code runs against it: enumerate every published year, pin a durable per-year PDF URL, confirm each year's General Fund column bookend-ties its printed totals at $0 via `pdftotext -table`, lock the deepest contiguous tying window per city, and return an explicit verdict on South Tucson's source. Output is `131-RECON.md` — the authoritative input for the extractor (Plan 131-02) and every Phase 132 load.

This plan does **no** code, no seed, no load, no schema touch. It is pure source validation + documentation. It mirrors the proven Tucson Plan 128-01.

<threat_model>
**T-131-01 — Fetching remote PDFs from multiple municipal hosts + running an external binary over network-sourced files.**
- *Surface:* recon downloads PDFs from four different city domains (and possibly azauditor.gov for South Tucson) and pipes them through the `pdftotext` binary.
- *Threats:* (a) fetching an arbitrary/attacker-controlled URL (SSRF / wrong-file); (b) shell injection if a URL or path is interpolated into a shell string; (c) trusting a filename pattern that silently 404s or returns an HTML error page saved as `.pdf`; (d) cross-city confusion — saving one town's ACFR under another's folder.
- *Mitigations:* restrict each fetch to that city's known host (`orovalleyaz.gov`, `maranaaz.gov`, `sahuaritaaz.gov`, and for South Tucson its own site or `azauditor.gov`) — a per-city allow-list, verified before pinning; before pinning any URL, verify **HTTP 200 + `Content-Type: application/pdf`** (reject HTML error pages); invoke `pdftotext` with an **args array** (no shell string, no `shell=True`); write each city's PDFs only into its own controlled `docs/<City>/` directory.
- *Block on:* medium. Do not pin a URL that fails the 200/PDF check; document it as a hole instead.
</threat_model>

<task id="131-01-02" type="execute">
<action>
For each downloaded Oro Valley / Marana / Sahuarita ACFR, locate the governmental-funds **Statement of Revenues, Expenditures and Changes in Fund Balances** page and extract it with `pdftotext -table` (args array; NEVER `-layout`). Reading the **General Fund column (the first data column)**, bookend-tie the year: sum the printed GF revenue-source rows and confirm it equals printed `Total revenues` at $0; sum the printed GF expenditure-function rows and confirm it equals printed `Total expenditures` at $0. Cross-check `Total revenues − Total expenditures == printed Excess (deficiency) of revenues over expenditures`. Note each statement's structure (which functions appear under `Current`; whether a separate Debt service / Capital projects section exists) — smaller towns often have a simpler function set than Tucson; this structure feeds Plan 131-02. Record the statement page and both tie deltas per city+year. A year whose statement is absent, image-only, or in a non-`-table`-tying layout is recorded as a non-extractable hole with the specific reason.
</action>
