<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local script → source ACFR PDFs (public web) | Untrusted external bytes (PDF) enter the harness; hosts can return HTTP 200 + HTML (soft-404) for a missing file. |
| local script → treasury.budgets (read) | Read-only DB access via service key (env-only). No write in this plan. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-01 | Tampering | source ACFR PDF fetch (soft-404) | mitigate | Filter fetches by Content-Type: application/pdf + multi-MB payload size, not HTTP status — a soft-404 HTML page must FAIL the check, never silently tie to 0. |
| T-110-02 | Information Disclosure | SUPABASE_SERVICE_KEY | accept | Key is read from ../.env.local/../.env only; never inlined in the script or the log. Read-only DB use. Standing project practice. |
| T-110-03 | Denial of Service | external PDF hosts (10 state sites) flaky | accept | Read-only re-fetch; if a host is intermittently unavailable, re-run (no DB state at risk). tn.gov needs browser UA (known). |
| T-110-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages — harness uses only Node built-ins + existing deps (the 106-harness pattern). No install task. |

Read-only DB queries + local PDF re-extraction; the only data-integrity-relevant threat is T-110-01 (soft-404 silently passing) — mitigated by content-type/size filtering.
