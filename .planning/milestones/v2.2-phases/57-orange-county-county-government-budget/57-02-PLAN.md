# Plan 57-02 — Render the OC county budget (SourceChip) + verify + document

**Mode:** standard
**Goal:** Surface the county budget loaded in Plan 57-01 on the OC county page with a federal-style `SourceChip` (D-03, OC county page only), prove coverage with a `verify-phase57.mjs` DB probe (exit 0), and document the load + ACFR cross-check in `57-VERIFICATION.md`. Satisfies OCB-02.

**Why the rendering is mostly free:** `App.tsx:615-617`'s `isCountyDirectoryOnly` lifts automatically once the county has budget rows, so the icicle/summary + year selector + per-capita render with no change; `CitiesInCountyPanel` (App.tsx:1200-1208) is independent of budget data, so the 34 cities keep listing. The only frontend code is a county-scoped SourceChip render — today the chip is gated to `entity_type==='federal'` (App.tsx:945-985), so the county currently shows no source tag.

<threat_model>
**T-57-02 — The SourceChip change regresses federal/city pages, or the OC county page ships an unsourced or broken source tag.**
- *Surface:* the federal SourceChip lives inside a federal-only block (App.tsx:945-985) that also holds federal-only Lens/Scale toggles. Widening that block's gate to include counties would render federal-only controls on the county page (regression). Conversely, a county chip built from a null/absent `data_source_info` would render an empty source name or a dead link — violating the always-sourced ground rule.
- *Threats:* federal/city visual or behavioral regression; a county chip with empty `sourceName`/`sourceUrl`; a chip linking to the raw `/resource/*.json` API endpoint instead of the durable `/d/<id>` page.
- *Mitigations:* add a SEPARATE, minimal county-scoped block (do not widen the federal gate); render the chip ONLY when `entity_type==='county'` AND `budgetData.metadata.dataSourceInfo` is non-null; use the non-federal `sourceUrl` branch (`datasetUrl || url`, App.tsx:967-970) so it links to the durable page; verify the API returns non-null `data_source_info` for the OC county before relying on it (if null, flag an EV-Accounts follow-up rather than shipping a blank chip).
- *Block on:* high for the unsourced-chip case (ground-rule violation); medium for the layout regression (caught by the federal/city no-regression acceptance check).
</threat_model>
