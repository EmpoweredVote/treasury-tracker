<objective>
Run the SAL-01 spike: confirm the statewide CA Government Compensation source
(publicpay.ca.gov, which 301-redirects to gcc.sco.ca.gov — the State Controller's
*Government Compensation in California / GCC*) covers Orange County cities at the depth
this phase needs, and **document the gate decision**. This spike is a HARD GATE — no
loader is built (Plan 55-02) until the 3-part pass condition in D-05 holds.

The 3-part pass condition (D-05):
1. **Access** — the source is programmatically reachable (raw CSV export and/or per-entity
   download) for OC cities with a realistic client, with no paywall/bot-block defeating automation.
2. **Shape** — the fields support a Department → Position tree summing on Total Compensation
   (entity name, department, position/job title, wages components, employer benefits).
3. **Sample match** — a sampled OC city/year's Total Compensation, computed from the raw
   source, reconciles against the figure published on the gcc.sco.ca.gov site.

Output: `55-SPIKE-FINDINGS.md` — an auditable record (access method, field→tree mapping,
OC coverage sample, sample reconciliation, and an explicit GATE: PASS/FAIL verdict). No
loader code is written in this plan.
</objective>

CA Government Compensation source (SAL-01 spike target):
  - Public entry: https://publicpay.ca.gov  →  301 Moved Permanently  →  https://gcc.sco.ca.gov
  - Raw data export page: https://gcc.sco.ca.gov/Reports/RawExport.aspx
    - Reported compensation as comma-delimited CSV, provided as compressed ZIP files, per YEAR.
    - Entity types covered include Cities, Counties, Special Districts, State (CSU etc.).
    - Updated every weekday morning. Roughly ~2009 through the latest reported year.
    - NO documented public REST/JSON API — primary programmatic access is the CSV/ZIP download.
  - Data dictionary: https://gcc.sco.ca.gov/Reports/DataDictionary.aspx (field definitions).
  - GCC publishes per-position records WITHOUT individual employee names (matches D-01).
  - BOT-BLOCK SIGNAL: during planning a plain markdown crawler received HTTP 403 from
    gcc.sco.ca.gov. The spike MUST test access with a realistic client (e.g. node global
    fetch or curl with a browser-like User-Agent) and record whether automation is blocked.
    This is exactly D-05 condition 1 — do not assume; prove it.

OC cities (the covered set to sample from) — from Phase 53/54:
  - 34 Orange County cities are loaded in the production Treasury DB (operating + revenue).
  - Anaheim and Santa Ana are custom-sourced for operating/revenue (do not disturb those rows;
    salaries is an additive, separate dataset_type — see Plan 55-03).

LA County salaries precedent (the loader Plan 55-02 will generalize — read for the shape target):
  - scripts/loadLACountySalaries.js — buildTree() (:85-159) emits the compact n/a/c/i tree
    (node name / amount / children / leaf items) summing on Total_Compensation; per-position
    wages/benefits breakdown (Base/Overtime/Other/Benefits); zero-comp rows skipped. This spike
    confirms the GCC raw export carries the equivalent fields so that tree can be built per city.
