# Milestone v1.4: Geographic Expansion

**Status:** ✅ SHIPPED 2026-05-22
**Phases:** 15–16

## Overview

Expand Treasury Tracker beyond Texas. Phase 15 (Los Angeles, CA) is the first non-TX city and proves the generic Socrata + enrichment pipeline scales to any US city with a Socrata SODA portal. Phase 16 adds San Francisco, San Diego, and LA revenue — completing the California cities expansion.

## Milestone Summary

**Key Decisions:**

- `where_extra` caller supplies the leading AND — more flexible (allows OR, parentheses); column_mapping per-dataset contract
- `fiscal_year_type` defaults to `'string'` (backward-compatible); only `'integer'` triggers unquoted branch
- `seedCaliforniaCities.js` uses primary name lookup only (no dataset_id+municipality_id fallback) — SF Op + Rev share xdgd-c79v + SF muni_id; fallback would collide
- LA Revenue enrichment was a no-op — all LA revenue department names matched existing Phase 15-03 enrichment rows via name_key deduplication (70 rows preserved, 0 new added, 0 API calls)
- LA Revenue `total_budget` has fractional cents from float accumulation in buildBudgetTree — cosmetic, pre-existing pattern
- `data_source_id` FK is null on SF/SD budget rows and LA Revenue FY2026 — pre-existing loader pattern; `data_source` text column populated; no UI impact
- Revenue dataset `6cbx-e2fd` (LA) excluded — only through FY2022, summary-level only (35 rows/year)
- `base_url` for LA must be `controllerdata.lacity.org` (NOT `data.lacity.org`) — two separate Socrata portals

**Issues Resolved:**

- Pre-existing "LA City Budget & Expenditures" row renamed to "Los Angeles Operating Budget" via fallback upsert by dataset_id+municipality_id — id preserved
- SD CSV fully double-quoted format — naive split(',') fails; quote-aware parseCSV() implemented
- LA FY2026 category_rows drift (519 vs 442) — total_budget exact; drift pre-existing from prior loads, not caused by Phase 16

**Issues Deferred:**

- `EntitySwitcher.tsx` `STATE_LABELS` incomplete: `{IN: 'Indiana', CA: 'California'}` only — TX cities show as "TX" not "Texas" in city picker (pre-existing, cosmetic)
- SD FY2026 budget_cycle blank in source — when SD publishes FY2026 adopted data, update `fiscal_years: [2025]` → `[2025, 2026]` in SD data_source rows (no code change)

**Technical Debt Incurred:**

- No VERIFICATION.md created for Phase 15 (human approval documented in 15-03-SUMMARY.md instead)
- `data_source_id` FK not reliably populated by `treasury_sync_budget_tree` — cosmetic, no current query path depends on it
