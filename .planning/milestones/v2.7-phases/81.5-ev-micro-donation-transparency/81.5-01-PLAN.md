## Task 1 — Compute distinct active recurring supporters + typical monthly (honest counting)
Add pure, exported helpers to `scripts/loadEVDonations.js` that derive, per fiscal year, from the already-parsed export rows:
- **distinct active recurring supporters**:
  - GiveButter: dedupe by `Contact ID` (fallback `Email`); count donors whose gifts are recurring-plan charges (has `Plan ID`/recurring `Frequency`).
  - Patreon: distinct active patrons for the FY from the detailed-earnings export (resolve the real distinct-patron count — do NOT use raw event-row count).
  - **Benevity: exactly 1 supporter** regardless of row count (Chris's company-matched recurring giving) — hard-coded rule with a comment citing the memory.
- **typical (median) monthly gift** across recurring supporters (anonymized, amounts only).
- **size buckets** (counts only): e.g. `<$5, $5–9, $10–24, $25–49, $50+` monthly.
Return a single `{ recurring_supporters, typical_monthly, buckets, as_of_fy }` object. **No names/emails/addresses in the output.**

**Verify:** unit assertions in `scripts/loadEVDonations.test.mjs` — Benevity collapses to 1; GiveButter dedupes 43 charges → its distinct-donor count; output object contains zero PII keys; median is a finite number.
