# Plan 49-03 — Agency-lens backfill loader (build + dry-run verify)

**Mode:** standard
**Goal:** Provide a historical agency lens. The FY2025 agency tree comes from MTS Table 5,
whose API history starts at FY2015 (verified) — useless for FY1976–FY2014. The OMB Public
Budget Database (the function loader's file) carries `agency`/`bureau`/`account` on every row
back to 1962, so the historical agency lens is the **same rows regrouped by agency hierarchy**.
Full depth, every year, one source, internally consistent with the function lens.

**Real writes deferred to 49-05.**

<threat_model>
**T-49-02 — Wrong-year or mis-sourced data (shared with 49-02).**
- *Agency-specific threats:* (a) double-counting if printed subtotal rows are summed (the MTS path's `Total--*` trap) — PBD rows are leaf accounts so this risk is lower, but bureau roll-ups must sum leaves only; (b) source discontinuity (FY2024 OMB vs FY2025 MTS) presented as if same-source.
- *Mitigations:* build strictly from leaf account amounts grouped by agency→bureau→account (no subtotal rows in PBD); reconcile the regrouped net to the same Hist 1.1 anchor as the function lens; tag the historical data_source name explicitly as "OMB Public Budget Database" so the per-year source label is honest and Phase 51 can note the FY2024/FY2025 source change.
- *Block on:* high.
</threat_model>
