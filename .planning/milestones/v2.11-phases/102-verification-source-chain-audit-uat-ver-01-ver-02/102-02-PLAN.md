<!-- Exact schema + invariant definitions — do not re-explore. -->
- **Basis label storage:** NASBO + ACFR budgets rows carry `data_source_id = null`; provenance is stamped into the row's `data_source` / `source_url` / `source_date` TEXT columns (policy P4). So "basis-labelled" = those text columns are non-null on every displayed state-node row. "residue/fragile" = a row in the `data_sources` table that is referenced by 0 live budgets rows (the stale `*-gf-*` artifacts).
- **Loaded windows (out-of-window check bounds):** CA FY2020–FY2025; TX FY2015–FY2024; NY FY2015–FY2024; FL FY2022–FY2024; the 46 NASBO states = FY2023–FY2024 (the NASBO operating window). A state-node budgets FY outside its window = out-of-window defect.
- **Uniqueness:** at most one budgets tree per (municipality_id, fiscal_year, dataset_type). More than one = dup.
- **Orphan (two directions):** a budgets row whose (non-null) data_source_id points to a missing data_sources row; OR a data_sources row of the `*-gf-*` family with 0 referencing live budgets rows (= residue, deleted in Task 2).
- **ACFR-GAAP label:** the 4 ACFR nodes' operating+revenue rows must carry the ACFR-GAAP `data_source` string created in 99/100 (e.g. `*-acfr-gf-operating` / `*-acfr-gf-revenue` provenance); the 46 NASBO nodes carry the NASBO-budgetary stamp.
- **Existing cleanup script:** `scripts/cleanupStaleStateGFDataSources.mjs` already deletes named stale state-GF `data_sources` guarded by a 0-live-rows assertion and supports `--state` filters (extended in phase 100 for NY/FL). Extend its target list / generalize it to sweep the full stale `*-gf-*` cohort.
- **DB client + .env pattern:** match `scripts/loadStateGF.mjs` / existing `verify-phaseNN.mjs` (source .env, Supabase service client). Read one before writing. mcp__supabase-local execute_sql is available for ad-hoc inline gap-closure if a defect is found.
