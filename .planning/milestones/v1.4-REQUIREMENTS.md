## v1.4 Requirements

### Los Angeles (Phase 15)

- [x] **LA-01**: `treasury.municipalities` has a row for Los Angeles, CA with population=3,878,704 and population_year=2024
- [x] **LA-02**: `treasury.data_sources` has a row for 'Los Angeles Operating Budget' (Socrata dataset `uyzw-yi8n` at `controllerdata.lacity.org`) — no code changes required to the generic loader
- [x] **LA-03**: LA operating budget FY2025 and FY2026 are loaded into `treasury.budgets` + `treasury.budget_categories` with totals in expected ranges (~$19.8B FY2025) and >= 50 top-level departments per year
- [x] **LA-04**: `treasury.category_enrichment` has rows for LA top-level categories, all with correct `municipality_id` (no NULL/universal bleed)
- [x] **LA-05**: Citizens visiting treasurytracker.empowered.vote see Los Angeles in the city picker, can browse the FY2025 and FY2026 operating budget with descriptions, and see per-capita spending labeled with "2024 Census estimate"

### California Cities (Phase 16)

- [x] **SF-01**: San Francisco operating + revenue data loaded from `data.sfgov.org` dataset `xdgd-c79v`
- [x] **SD-01**: San Diego operating + revenue data loaded from static CSV at seshat.datasd.org
- [x] **LA-REV-01**: LA revenue data loaded from `controllerdata.lacity.org` dataset `vvm4-a2zu`
- [x] **CA-01**: All three cities have plain-language enrichment on top-level categories
- [x] **CA-02**: All three cities display per-capita spending with correct Census population year
