<objective>
Extend the proven Phase 84/85 loader + batch driver to handle COUNTIES with a minimal, regression-safe delta: an `entityType` parameter (so counties write as `entity_type='county'`), an entity-type-aware source manifest selector, and a committed `scripts/ohioAosCountyDatasets.json`. Prove the full county roster parses and assigns correctly via `--dry-run` + offline tests. No live county load happens here — that is plan 86-02.

The county workbook has the SAME tab structure as cities (verified: `detectLayout`, `enumerateCities`, the tree-builders, `cityPopulation`, `cityCounty` all work unchanged on `County_2024_GAAP_Summarized.XLSX`, which enumerates 63 counties). So the only genuinely new code is (1) thread `entity_type` through the write path, (2) point the manifest resolver at a county file, and (3) a `--entity-type` CLI switch. Everything else is reused verbatim.
</objective>
