<objective>
Load operating (EX) + revenue (RV) for the 5 Utah county governments onto their own `entity_type='county'` entities for FY2014–FY2025, and set 2024 Census county population so per-capita renders (UCO-01, SC#1). This requires first fixing the verified D-70-04 loader bug: `importEntityData` hardcodes `p_entity_type:'city'`, which would NOT match a seeded county row (`treasury_ensure_municipality` keys on name+state+entity_type) and would INSERT a duplicate city-typed "Salt Lake County" phantom. Add an `--entity-type` flag (default `city`) and run the county loads with `--entity-type county`.

Purpose: counties carry the same all-funds fund1→org1→cat1 tree as the cities (D-70-01) — pure reuse of the proven Phase 69 loader, only the entity_type + population file differ.
Output: the loader fix + 5 county entities carrying op+rev (FY2014–FY2025) + county population, with the 10 city rows untouched (never-overwrite, SC#4).
</objective>
