Recon the Batch-2 candidate states (TN, CT, WI, WA, MI) for the v2.13 State-ACFR upgrade. For each state: locate the ACFR Governmental Funds *Statement of Revenues, Expenditures and Changes in Fund Balances* → **GENERAL FUND column** (GAAP), find its durable per-year URL pattern, establish the cleanly `pdftotext -table`-extractable clean window, bookend-tie-confirm that window (oldest + latest FY), pin the four risk facts, compare ACFR GF scope vs NASBO, map it to the closest existing loader template, and gap-log every year that doesn't cleanly extract or lack a durable URL.

Purpose: This is the input contract for Phase 109 (Batch 2 loads). It de-risks the loads before any write. **Documentation only — no DB writes, no NASBO mutations, no loader code, no frontend, $0 (pdftotext only, no AI).**
Output: `.planning/phases/107-recon-acfr-source-location-roster-lock-overlap-resolution-re/107-BATCH2-SOURCES.md` — the per-state source doc mirroring the Phase 98/103 shape.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public state ACFR site → local disk | untrusted PDF/HTML fetched over the network into a local working dir |

This is a documentation-only, read-only recon plan: it fetches public ACFR PDFs, runs `pdftotext`, and writes local markdown. No DB, no secrets, no user input, no network writes. The honest threat surface is minimal.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-107-01 | Spoofing/Tampering | fetched "ACFR" PDF that is actually a soft-404 HTML page (HTTP 200 + HTML body) mistaken for a real document | mitigate | Filter every download by Content-Type `application/pdf` or size (>~1MB), never by HTTP status alone (CA-SCO soft-404 caution, 98-RECON). Confirm the exact statement title + "General Fund" column header + units before trusting any extracted figure. |
| T-107-02 | Tampering | extracting the wrong statement (government-wide Statement of Activities, or a budgetary/forecast schedule) instead of the Governmental Funds GENERAL FUND column | mitigate | Confirm the statement title is "Statement of Revenues, Expenditures and Changes in Fund Balances — Governmental Funds" and the column header is the General Fund column; tie the extracted GF Total revenues to the printed page total before recording (D-05/D-08.3). |
| T-107-03 | Tampering | recording a non-durable (Wayback/one-off) URL that will rot, breaking the always-sourced standard | mitigate | Reject non-durable-only years to the gap log (D-06); only a stable re-fetchable per-year URL pattern is recorded as loadable. |

No package installs in this plan (poppler `pdftotext` is a pre-existing system tool) → no supply-chain checkpoint needed.
</threat_model>
