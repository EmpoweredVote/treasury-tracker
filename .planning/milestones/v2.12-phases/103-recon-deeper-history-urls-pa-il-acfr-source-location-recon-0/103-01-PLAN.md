# Plan 103-01 — Pilot deepening recon (deeper-history URLs + gap log)

**Mode:** standard
**Goal:** For each v2.11 pilot, locate the durable per-year ACFR URLs *below* its current window — FL pre-FY2022, CA pre-FY2020, NY pre-FY2015, and the within-window TX FY2016 gap — bookend-tie-confirm the newly-reachable FY depth via `pdftotext -table`, and write a per-state gap log for years that don't cleanly extract or lack a durable URL. Documentation only; no DB writes; $0. Satisfies the pilot half of RECON-04 and feeds Phase 104's `SOURCES`-map extensions.

<threat_model>
**T-103-01 — A wrong or non-durable deeper-history URL lets Phase 104 transcribe a garbled/unsourceable older FY into a pilot's SOURCES map.**
- *Surface:* navigating SCO / myfloridacfo / OSC archive pages; downloading older public ACFR PDFs to a local working dir; running pdftotext; recording URLs + FY depth + gap log.
- *Threats:* (a) the CA SCO soft-404 (HTTP 200 + HTML body) saved as ".pdf" and mistaken for a real document; (b) extracting the government-wide Statement of Activities or a budgetary schedule instead of the Governmental Funds GENERAL FUND column in an older ACFR whose layout drifted; (c) recording a Wayback/one-off link that will rot, breaking the always-sourced standard; (d) claiming a deeper FY is clean without tying its GF total to the printed page total.
- *Mitigations:* filter every download by Content-Type/size, not HTTP status (D-02 + 98 soft-404 caution); verify the exact statement title + "General Fund" column header + units before extracting; reject non-durable-only years to the gap log (D-02); for each kept bookend FY confirm the extracted GF total ties to the printed total; cap the dig per state at the D-01 effort budget so a fruitless archive hunt can't run unbounded.
- *Block on:* high.
</threat_model>
