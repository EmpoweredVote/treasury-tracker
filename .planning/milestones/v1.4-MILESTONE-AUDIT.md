## Tech Debt

### Non-blocking — no action required before shipping

**Phase 15 — Missing VERIFICATION.md**
Human verification documented in 15-03-SUMMARY.md. All success criteria confirmed in plan summaries. Not a functional gap; the data and UI are correct.

**Phase 16 — EntitySwitcher STATE_LABELS incomplete**
`/src/components/EntitySwitcher.tsx` line 21: `{ IN: 'Indiana', CA: 'California' }` — TX falls back to the two-letter code "TX" as the city group header. Pre-existing issue (v1.2 or earlier); not introduced by v1.4. Cosmetic only; all TX city data loads correctly.

**Phase 16 — data_source_id FK null on some budget rows**
SF/SD operating+revenue and LA Revenue FY2026 have `data_source_id=null` (the `data_source` text column is populated). Pre-existing `treasury_sync_budget_tree` pattern. No UI or query path uses `data_source_id` for foreign-key joins. Acknowledged in VERIFICATION.md.

**Phase 16 — LA Revenue total_budget fractional cents**
$10,223,013,860.70 and $10,112,263,131.69. Float accumulation in `buildBudgetTree`'s running total. Cosmetic; category amounts display correctly. Pre-existing pattern across other budgets.

**Phase 16 — SD FY2026 not yet published**
Source CSV has blank `budget_cycle` for FY2026 rows. When San Diego publishes FY2026 adopted data, the only required change is updating `fiscal_years: [2025]` → `[2025, 2026]` in SD's data_source rows — no code change needed.
