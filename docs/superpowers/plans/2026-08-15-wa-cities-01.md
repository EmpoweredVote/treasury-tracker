# WA-CITIES-01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Onboard the six largest Washington cities not already in Treasury Tracker — Tacoma, Spokane, Vancouver, Bellevue, Kent, Everett — onto the WA State Auditor pipeline built in v2.22, at General Fund parity with every figure durably sourced.

**Architecture:** Reuse `scripts/lib/waSao.mjs` (MCAG-generic SAO client + content guard) and `scripts/lib/waSaoLoad.mjs` (`loadEntity(descriptor)` — tie gate, per-capita band, source-URL validation, ephemeral `data_sources` lifecycle) unchanged. Add one shared entity roster module that the seeder, loaders and all three verification harnesses read, so adding a city is a roster entry plus an extractor config rather than an edit in six places. Tacoma runs first as a shape-finder; the other five follow on whatever shape it proves.

**Tech Stack:** Node ESM (`.mjs`), Python 3 (`py -3`) for extractors on `scripts/lib/acfrGF.py`, `pdftotext`/`pdfinfo`/`pdftoppm` from poppler, Supabase (`treasury` schema) via `treasury_sync_budget_tree`, vitest for JS tests, unittest for extractor selftests.

**Spec:** `docs/superpowers/specs/2026-08-15-wa-cities-01-design.md` — read it first. This plan argues from it and does not restate its reasoning.

## Global Constraints

Every task's requirements implicitly include this section. Values copied verbatim from the spec.

- **General Fund basis only.** Consistent with Seattle, King County, Bainbridge, Kitsap.
- **FY floor is per city and mechanical.** Walk back from FY2025. The window ends at the first year that needs **anything beyond a value change in that city's existing config** — an era-split/second config, a font or OCR recovery, or a different source. An **isolated** unreadable year inside the window is documented and skipped and the walk continues; **two consecutive** unreadable years end it.
- **Never extend a window by doing not-easy work to make the row count look better.** Row count is an output of recon, not a target.
- **Select reports by CONTENT, never by type name.** `classifyReport()` requires page count ≥ 40 plus a located governmental-funds statement anchor. The type named *Annual Comprehensive Financial Report* is a 4–5 page opinion letter for FY2014+.
- **Nothing may trust a type name below FY2014** because "it's the older format". Record what the names do there as a finding; do not rely on it.
- **MCAG must match the roster exactly.** Select the entity named exactly `City of <Name>`; reject any `(Inactive)` entity or district/corporation suffix. An MCAG mismatch loads the wrong government's money in a perfectly self-consistent way that every arithmetic gate passes.
- **Unusable city → substitute the next-largest** WA city not already in TT and not already in the roster, by WA OFM population, with a written verdict. A city whose SAO filings are opinion letters only counts as unusable — **do NOT silently pivot it to its own ACFR** unless that ACFR needs nothing beyond a value change.
- **Counties are nav-only.** Pierce, Spokane, Clark, Snohomish get nodes with no budget rows. Bellevue and Kent link to the **existing** King County node.
- **Per-capita band is re-derived per city.** Never copy another entity's band. Seattle's `[500, 25000]` rejects a correct Kitsap load.
- **Units are read off the page**, never configured by assumption.
- **Never trust a filename for fiscal year** — bind FY from the page's own period sentence.
- **Enrichment rows always carry a non-NULL `municipality_id`.** A NULL is treated as universal and bleeds onto every other city.
- **Write path is `treasury_sync_budget_tree` only** (source-safe). Never `treasury_sync_city_budget`.
- **No `scripts/lib/*.mjs` may start with `#!`** — a shebang breaks `npm test` on Windows and a test guards this.
- **Free PDFs only, $0 spend, no AI calls.** Executed inline — no subagents.
- **`npm run lint` is excluded** from every gate. It is broken in this repo and has never exited 0.
- **Population from WA OFM April 1 estimates**, recorded with the exact table read. Never a third-party estimate.

export function getEntity(name) {
  const e = WA_ENTITIES.find((x) => x.name === name);
  if (!e) throw new Error(`"${name}" is not in the WA roster (scripts/lib/waRoster.mjs)`);
  return e;
}

export const cityEntities = () => WA_ENTITIES.filter((e) => e.entityType === 'city');
export const countyEntities = () => WA_ENTITIES.filter((e) => e.entityType === 'county');

/** Entities ready to load: reconned window, population and band all present. */
export function loadableEntities() {
  return WA_ENTITIES.filter((e) => !e.navOnly && e.fiscalYears && e.population && e.perCapitaBand);
}

/**
 * Pick the exact `City of <Name>` row out of a GetEntities response.
 *
 * The endpoint matches on a name PREFIX, so this must reject decoys rather
 * than take the first hit. Observed 2026-08-15: "Spokane" returns City of
 * Spokane, City of Spokane VALLEY (a different municipality) and an Inactive
 * transportation benefit district; "Kent" returns two inactive districts.
 */
export function selectExactCity(candidates, cityName) {
  const want = `city of ${cityName}`.toLowerCase();
  const hits = (candidates || []).filter((r) => {
    const n = String(r.EntityName || r.Name || '').trim().toLowerCase();
    return n === want;
  });
  if (hits.length !== 1) {
    throw new Error(
      `no exact "City of ${cityName}" entity in ${candidates.length} candidate(s) ` +
      `(found ${hits.length}); candidates: ${(candidates || []).map((r) => r.EntityName || r.Name).join(' | ')}`);
  }
  return hits[0];
}

/** Assert a resolved MCAG against the pinned roster value. */
export function assertMcag(cityName, resolvedMcag) {
  const pinned = getEntity(cityName).mcag;
  if (String(resolvedMcag) !== pinned) {
    throw new Error(
      `${cityName}: resolved MCAG ${resolvedMcag} does not match the pinned MCAG ${pinned} — ` +
      `refusing to continue. An MCAG mismatch loads a DIFFERENT government's money and ties at $0.`);
  }
  return pinned;
}

- [ ] **Step 2: Write the fetcher**

Create `scripts/fetchWaCities.mjs`, mirroring `scripts/fetchBainbridgeKitsap.mjs`. It **keeps its shebang** — it is an entry-point script with a main guard, not a `scripts/lib/` module.

```javascript
#!/usr/bin/env node
/**
 * Downloads WA SAO bound financial statements for the WA-CITIES-01 cities
 * into gitignored docs/ directories.
 *
 * ARNs are resolved by probing SearchReports per MCAG and pinned here so a
 * load is reproducible and reviewable. Every downloaded file is passed
 * through classifyReport() -- an ARN that turns out to be an opinion letter
 * or a scan fails LOUDLY at fetch time rather than yielding an empty
 * extraction later. That guard is what answers the spec's largest open
 * risk: whether the SAO holds statements for a city this size at all.
 */
import { mkdirSync, writeFileSync, existsSync, statSync } from 'node:fs';
import { execFileSync } from 'node:child_process';
import { pathToFileURL } from 'node:url';
import { fetchReportPdf, classifyReport } from './lib/waSao.mjs';
import { getEntity } from './lib/waRoster.mjs';

// Filled per city by that city's recon task. FY -> ARN.
export const TACOMA_ARNS = {};
export const SPOKANE_ARNS = {};
export const VANCOUVER_ARNS = {};
export const BELLEVUE_ARNS = {};
export const KENT_ARNS = {};
export const EVERETT_ARNS = {};

export const ARNS_BY_CITY = {
  Tacoma: TACOMA_ARNS, Spokane: SPOKANE_ARNS, Vancouver: VANCOUVER_ARNS,
  Bellevue: BELLEVUE_ARNS, Kent: KENT_ARNS, Everett: EVERETT_ARNS,
};

function pageCount(pdfPath) {
  const out = execFileSync('pdfinfo', [pdfPath], { encoding: 'utf8' });
  const m = /^Pages:\s+(\d+)/m.exec(out);
  if (!m) throw new Error(`pdfinfo gave no page count for ${pdfPath}`);
  return Number(m[1]);
}

function pdfText(pdfPath) {
  return execFileSync('pdftotext', ['-layout', pdfPath, '-'],
    { encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 });
}

async function fetchOne(arn, dest) {
  if (!(existsSync(dest) && statSync(dest).size > 100_000)) {
    writeFileSync(dest, await fetchReportPdf(arn));
  }
  const verdict = classifyReport(pageCount(dest), pdfText(dest));
  if (!verdict.ok) throw new Error(`ARN ${arn} rejected: ${verdict.reason}`);
  return `${(statSync(dest).size / 1e6).toFixed(1)} MB — ${verdict.reason}`;
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const only = process.argv[2];
  let failures = 0;
  for (const [city, arns] of Object.entries(ARNS_BY_CITY)) {
    if (only && city !== only) continue;
    const e = getEntity(city);
    mkdirSync(e.pdfDir, { recursive: true });
    for (const fy of Object.keys(arns).map(Number).sort((a, b) => b - a)) {
      const dest = `${e.pdfDir}/${e.pdfPrefix}-${fy}-acfr.pdf`;
      try { console.log(`${e.pdfPrefix} FY${fy}: ${await fetchOne(arns[fy], dest)}`); }
      catch (err) { failures++; console.error(`${e.pdfPrefix} FY${fy}: FAILED — ${err.message}`); }
    }
  }
  if (failures) { console.error(`\n${failures} file(s) failed the content guard.`); process.exit(1); }
}
```

```javascript
#!/usr/bin/env node
/**
 * Creates the WA-CITIES-01 county nodes and cities in treasury.municipalities.
 *
 * Order matters: a county must exist before a city can point county_id at it.
 * Idempotent -- re-running updates rather than duplicating.
 *
 * The four new counties are NAV-ONLY: a node for the breadcrumb, with no
 * budget rows, matching the v2.17/v2.18 Pima precedent. Bellevue and Kent
 * link to the EXISTING King County node from v2.21 and must not create a
 * second one.
 *
 * geo_id and hero_image_url are left NULL, matching every other WA entity.
 */
import { createClient } from '@supabase/supabase-js';
import { readFileSync } from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { WA_ENTITIES, getEntity } from './lib/waRoster.mjs';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
for (const f of ['.env', '.env.local']) {
  try {
    for (const line of readFileSync(path.join(ROOT, f), 'utf8').split('\n')) {
      const [k, ...v] = line.split('=');
      if (k && v.length && !process.env[k.trim()]) process.env[k.trim()] = v.join('=').trim();
    }
  } catch { /* absent is fine */ }
}
const SUPABASE_KEY = process.env.SUPABASE_SERVICE_KEY || process.env.SUPABASE_SERVICE_ROLE_KEY;
if (!process.env.SUPABASE_URL) { console.error('Missing SUPABASE_URL'); process.exit(1); }
if (!SUPABASE_KEY) { console.error('Missing SUPABASE_SERVICE_KEY'); process.exit(1); }
const db = createClient(process.env.SUPABASE_URL, SUPABASE_KEY, { db: { schema: 'treasury' } });

const POPULATION_YEAR = 2025;

async function findId(name) {
  const { data } = await db.from('municipalities')
    .select('id').eq('name', name).eq('state', 'WA').maybeSingle();
  return data ? data.id : null;
}

async function upsertEntity(entity, countyId) {
  const row = { name: entity.name, state: 'WA', entity_type: entity.entityType, county_id: countyId };
  if (!entity.navOnly) {
    if (!Number.isInteger(entity.population)) {
      throw new Error(`${entity.name}: population is not set — read it from WA OFM first (recon task).`);
    }
    row.population = entity.population;
    row.population_year = POPULATION_YEAR;
  }
  const existingId = await findId(entity.name);
  const q = existingId
    ? db.from('municipalities').update(row).eq('id', existingId).select().single()
    : db.from('municipalities').insert(row).select().single();
  const { data, error } = await q;
  if (error) throw new Error(`${entity.name}: ${error.message}`);
  console.log(`  ${existingId ? 'Updated' : 'Created'} ${entity.name} (${entity.entityType}` +
    `${entity.navOnly ? ', nav-only' : `, pop ${entity.population.toLocaleString()}`}) ${data.id}`);
  return data.id;
}

export async function getMuniId(name) {
  const id = await findId(name);
  if (!id) throw new Error(`${name} is not seeded — run scripts/seedWaCities.mjs first`);
  return id;
}

const ONLY = process.argv[2] || null;

// Counties first.
const countyIds = new Map();
for (const c of WA_ENTITIES.filter((e) => e.entityType === 'county' && e.navOnly)) {
  countyIds.set(c.name, await upsertEntity(c, null));
}
// King County already exists from v2.21 and must NOT be recreated here.
const kingId = await findId('King County');
if (!kingId) throw new Error('King County is missing — it should exist from v2.21. Refusing to create it here.');
countyIds.set('King County', kingId);
console.log(`  Reused existing King County ${kingId} (v2.21) — not recreated`);

for (const city of WA_ENTITIES.filter((e) => e.entityType === 'city' && !e.navOnly)) {
  if (ONLY && city.name !== ONLY) continue;
  if (city.population === null) { console.log(`  Skipping ${city.name} — not yet reconned`); continue; }
  const countyId = countyIds.get(city.countyName);
  if (!countyId) throw new Error(`${city.name}: county ${city.countyName} was not seeded`);
  await upsertEntity(city, countyId);
}

// Guard against the Utah phantom-row defect: a load run without the right
// entity type silently creates a second, differently-typed row of the same name.
const names = WA_ENTITIES.map((e) => e.name);
const { data: all } = await db.from('municipalities').select('name, entity_type').eq('state', 'WA').in('name', names);
const dupes = all.filter((r, i) => all.findIndex((x) => x.name === r.name) !== i);
if (dupes.length) { console.error('Duplicate rows:', dupes); process.exit(1); }
console.log('\nSeed OK.');
```
