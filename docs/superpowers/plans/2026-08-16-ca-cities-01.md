# CA-CITIES-01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **This repo executes inline — no research/roadmapper subagents** (auto-memory `feedback_no_research_subagents`).

**Goal:** Bring Irvine, Stockton, Santa Clarita, Modesto and Chula Vista onto audited GAAP General Fund actuals from each city's own ACFR, and in the same pass measure — for the first time in this project — how the State Controller's figures compare to the audited figures for the same city-year.

**Architecture:** A per-city ACFR pipeline in the established Bend/Tucson mould (`extract<City>.py` over the shared `scripts/lib/acfrGF.py`, then `process<City>.js` writing through the source-safe `treasury_sync_budget_tree` RPC), gated by a new reconciliation engine that compares each extracted city-year against the SCO rows already in the database. Reconciliation runs *before* the load, not after: a year whose divergence cannot be explained is never written, and the SCO row it would have replaced is left untouched.

**Tech Stack:** Node ESM (`.mjs`) + Python 3 (`pdfplumber`, `pdftotext`) · Supabase Postgres (`treasury` schema) · vitest (`tests/**/*.test.mjs`, `src/**/*.test.ts`)

**Spec:** `docs/superpowers/specs/2026-08-16-ca-cities-01-design.md`

## Global Constraints

Every task's requirements implicitly include this section. Values copied verbatim from the spec.

- **General Fund basis only.** Consistent with every city onboarded since v2.21.
- **Audited GAAP actuals only.** City ACFR, governmental-funds Statement of Revenues, Expenditures and Changes in Fund Balances, General Fund column. **Never an adopted budget** — the six existing CA deep cities load adopted budgets and that is the pattern this milestone deliberately does not follow.
- **This is not a recency milestone.** ACFR actuals top out at FY2024, the same year SCO already reaches. Do not extend scope chasing FY2025–26; that requires adopted budgets, which are out of scope.
- **ACFR supersedes SCO only for a year that reconciles.** One source per (muni, fy, dataset). SCO is retained for every year ACFR does not reach or does not reconcile.
- **UNEXPLAINED divergence blocks that year's load.** It is not a milestone failure and must never be resolved by widening the threshold. Adding a structural-divergence reason is a deliberate, recorded act with the evidence that established it.
- **The recon document lists every overlapping city-year, ties included.** A recon that lists only problems cannot be audited for completeness, because a year never checked is indistinguishable from a year that passed.
- **`population_year` is set during the load, and per-capita display is gated on it.** Where a properly-yeared population cannot be sourced for a year, per-capita is **off** for that year. A per-capita band is never inherited from another entity or another year.
- **Write path is `treasury_sync_budget_tree` only** (source-safe). Never `treasury_sync_city_budget` — it overwrites existing (muni, fy, dataset) rows and keeps the stale `data_source` label (auto-memory `project_sync_city_budget_not_source_safe`).
- **Never trust a filename for fiscal year** — bind FY from the page's own period sentence via `acfrGF.parse_fy`.
- **Units are read off the page**, never configured by assumption.
- **Select the statement page by CONTENT**, never by a document's table of contents or title.
- **Enrichment rows always carry a non-NULL `municipality_id`.** A NULL is treated as universal and bleeds onto every other city.
- **No `scripts/lib/*.mjs` may start with `#!`** — a shebang breaks `npm test` on Windows and a test guards this (commit `40aa706`).
- **Unusable city → substitute the next-largest**, in order: San Bernardino (194,120) → Huntington Beach (192,503) → Glendale (191,284).
- **Free documents only, $0 API spend, no AI calls.** Executed inline, no subagents.
- **`npm run lint` is excluded** from every gate. It is broken in this repo and has never exited 0.

// tests/caRecon.test.mjs
import { describe, it, expect } from 'vitest';
import { reconcile, BUCKET } from '../scripts/lib/caRecon.mjs';

const cal = {
  tieAbs: 1000,
  tiePct: 0.001,
  depthRatio: 0.5,
  structural: [
    { id: 'TRANSFERS-OUT', note: 'SCO folds transfers out into expenditure', test: (c) => c.unmatchedSco.includes('Transfers Out') },
  ],
};

const tree = (total, cats, lineItemCount) => ({
  total,
  categories: cats.map(([name, amount]) => ({ name, amount })),
  lineItemCount,
});

describe('reconcile — bucketing', () => {
  it('calls an exact match a tie', () => {
    const r = reconcile(tree(100, [['Police', 100]], 5), tree(100, [['Police', 100]], 5), cal);
    expect(r.bucket).toBe(BUCKET.TIE);
    expect(r.deltaAbs).toBe(0);
    expect(r.loadable).toBe(true);
  });

  it('calls a delta inside the absolute threshold a tie', () => {
    const r = reconcile(tree(100_900, [['Police', 100_900]], 5), tree(100_000, [['Police', 100_000]], 5), cal);
    expect(r.bucket).toBe(BUCKET.TIE);
  });

  it('calls a large-city delta inside the percentage threshold a tie', () => {
    // 500M city, 400k delta: over tieAbs, under tiePct. Both thresholds must apply.
    const r = reconcile(tree(500_400_000, [['Police', 500_400_000]], 5), tree(500_000_000, [['Police', 500_000_000]], 5), cal);
    expect(r.bucket).toBe(BUCKET.TIE);
  });

  it('explains a divergence that matches a registered structural reason', () => {
    const acfr = tree(90_000, [['Police', 90_000]], 5);
    const sco = tree(120_000, [['Police', 90_000], ['Transfers Out', 30_000]], 6);
    const r = reconcile(acfr, sco, cal);
    expect(r.bucket).toBe(BUCKET.EXPLAINED);
    expect(r.reason).toBe('TRANSFERS-OUT');
    expect(r.loadable).toBe(true);
  });

  it('leaves an unmatched divergence UNEXPLAINED and unloadable', () => {
    const r = reconcile(tree(90_000, [['Police', 90_000]], 5), tree(120_000, [['Police', 120_000]], 5), cal);
    expect(r.bucket).toBe(BUCKET.UNEXPLAINED);
    expect(r.reason).toBeNull();
    expect(r.loadable).toBe(false);
  });

  it('defaults to UNEXPLAINED when the calibration has no rules yet', () => {
    // The safety property: an empty catalogue must block, never wave through.
    const empty = { ...cal, structural: [] };
    const r = reconcile(tree(90_000, [['Police', 90_000]], 5), tree(120_000, [['Police', 120_000]], 5), empty);
    expect(r.bucket).toBe(BUCKET.UNEXPLAINED);
  });

  it('does not let a throwing structural rule pass a year', () => {
    const bad = { ...cal, structural: [{ id: 'BOOM', note: 'x', test: () => { throw new Error('bang'); } }] };
    const r = reconcile(tree(90_000, [['Police', 90_000]], 5), tree(120_000, [['Police', 120_000]], 5), bad);
    expect(r.bucket).toBe(BUCKET.UNEXPLAINED);
  });

  it('survives a zero SCO total without dividing by zero', () => {
    const r = reconcile(tree(500, [['Police', 500]], 1), tree(0, [], 0), cal);
    expect(Number.isFinite(r.deltaPct)).toBe(true);
    expect(r.bucket).toBe(BUCKET.UNEXPLAINED);
  });
});

describe('reconcile — the depth flag is orthogonal to the bucket', () => {
  it('flags a tie whose ACFR is materially coarser than the SCO row it would replace', () => {
    // Modesto's real shape: SCO FY2024 operating is 32 categories / 83 line items.
    const acfr = tree(100, [['Current', 100]], 6);
    const sco = tree(100, Array.from({ length: 32 }, (_, i) => [`Cat${i}`, i]), 83);
    const r = reconcile(acfr, sco, cal);
    expect(r.bucket).toBe(BUCKET.TIE);
    expect(r.depthFlag).toBe(true);
    expect(r.loadable).toBe(false);   // held pending an explicit call
  });

  it('does not flag depth when the ACFR is at least as granular', () => {
    const acfr = tree(100, [['A', 50], ['B', 50]], 40);
    const sco = tree(100, [['A', 50], ['B', 50]], 39);
    expect(reconcile(acfr, sco, cal).depthFlag).toBe(false);
  });
});

describe('reconcile — reporting', () => {
  it('lists unmatched categories on both sides rather than dropping them', () => {
    const acfr = tree(100, [['Police', 60], ['Library', 40]], 2);
    const sco = tree(100, [['Police', 60], ['Parks', 40]], 2);
    const r = reconcile(acfr, sco, cal);
    expect(r.unmatchedAcfr).toEqual(['Library']);
    expect(r.unmatchedSco).toEqual(['Parks']);
  });
});

```javascript
/**
 * CA-CITIES-01 cross-source reconciliation.
 *
 * Compares one extracted ACFR city-year against the State Controller row already
 * in the database for the same (muni, fy, dataset). Pure: no DB, no filesystem,
 * no network, so the gate that decides whether real data gets overwritten is
 * testable without a PDF.
 *
 * THE DEFAULT IS UNEXPLAINED. Divergence is only ever downgraded to EXPLAINED by
 * a rule that was deliberately registered with the evidence that established it.
 * A missing catalogue, a malformed rule or a throwing rule all leave the year
 * blocked -- the failure direction is "do not overwrite", always.
 */

export const BUCKET = {
  TIE: 'TIE',
  EXPLAINED: 'EXPLAINED',
  UNEXPLAINED: 'UNEXPLAINED',
};

const norm = (s) => String(s).toLowerCase().trim().replace(/\s+/g, ' ');

export function reconcile(acfr, sco, cal) {
  const deltaAbs = acfr.total - sco.total;
  // A zero SCO total makes a percentage meaningless rather than infinite.
  const deltaPct = sco.total === 0 ? (deltaAbs === 0 ? 0 : 1) : deltaAbs / sco.total;

  const acfrNames = new Map(acfr.categories.map((c) => [norm(c.name), c.name]));
  const scoNames = new Map(sco.categories.map((c) => [norm(c.name), c.name]));
  const unmatchedAcfr = [...acfrNames].filter(([k]) => !scoNames.has(k)).map(([, v]) => v);
  const unmatchedSco = [...scoNames].filter(([k]) => !acfrNames.has(k)).map(([, v]) => v);

  const depth = {
    acfrCategories: acfr.categories.length,
    scoCategories: sco.categories.length,
    acfrLineItems: acfr.lineItemCount,
    scoLineItems: sco.lineItemCount,
  };
  // Materially coarser: the ACFR carries less than depthRatio of SCO's line items.
  const depthFlag = sco.lineItemCount > 0
    && acfr.lineItemCount < sco.lineItemCount * cal.depthRatio;

  const ties = Math.abs(deltaAbs) <= cal.tieAbs || Math.abs(deltaPct) <= cal.tiePct;

  let bucket = BUCKET.UNEXPLAINED;
  let reason = null;

  if (ties) {
    bucket = BUCKET.TIE;
  } else {
    const ctx = { acfr, sco, deltaAbs, deltaPct, unmatchedAcfr, unmatchedSco, depth };
    for (const rule of cal.structural ?? []) {
      let hit = false;
      try {
        hit = rule.test(ctx) === true;
      } catch {
        hit = false;   // a broken rule never explains anything
      }
      if (hit) {
        bucket = BUCKET.EXPLAINED;
        reason = rule.id;
        break;
      }
    }
  }

  const loadable = bucket !== BUCKET.UNEXPLAINED && !depthFlag;

  return { bucket, reason, deltaAbs, deltaPct, depthFlag, depth, unmatchedAcfr, unmatchedSco, loadable };
}
```

- [ ] **Step 1: Write the driver**

`scripts/reconcileCaCity.mjs` — CLI, so it **may** carry a shebang (it is not under `scripts/lib/`).

Usage: `node scripts/reconcileCaCity.mjs --city Modesto [--dry-run]`

For each FY in the city's roster window it must:
1. Run `scripts/extract<City>.py` for both modes and read the emitted tree.
2. Read the SCO row from the DB for the same (muni, fy, dataset), reconstructing `{total, categories, lineItemCount}` from `treasury.budgets` → `budget_categories` → `budget_line_items`.
3. Call `reconcile(acfr, sco, CA_CALIBRATION)`.
4. Append the result to `scripts/data/ca-recon.json`.

**A city-year with no SCO row is not an error** — record it with `bucket: 'TIE'`, `reason: 'NO-SCO-ROW'` and `loadable: true`. There is nothing to contradict. **A city-year with no ACFR extraction is also not an error** — it is simply outside the window and is not written at all.
